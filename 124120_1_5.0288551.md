## ABSTRACT

Molecular exciton-polaritons exhibit long-range, ultrafast propagation, yet recent experiments have reported far slower propagation than expected. In this work, we implement a nonperturbative approach to quantify how static energetic disorder renormalizes polariton group velocity in strongly coupled microcavities. The method requires no exact diagonalization or master equation propagation and depends only on measurable parameters: the mean exciton energy and its probability distribution, the microcavity dispersion, and the Rabi splitting. Using parameters corresponding to recently probed organic microcavities, we show that exciton inhomogeneous broadening slows both lower and upper polaritons, particularly when the mean exciton energy fluctuation approaches the collective light–matter coupling strength. A detailed discussion and interpretation of these results is provided using perturbation theory in the limit of weak resonance scattering. The magnitude of the effects examined in this work supports the conclusion that most of the reported polaritonic slowdown arises from dynamical (phonon-assisted) disorder, with static energetic disorder contributing only secondarily.

## INTRODUCTION

Hybrid light–matter excitations, denoted polaritons,1–5 have emerged as promising mediators of long-range, ultrafast, and crucial for new optoelectronic technologies.23–25 In contrast with molecular exciton transport, which is typically short-ranged and diffusive,26,27 the hybrid light–matter character of exciton-polaritons28,29 enables ballistic energy flow in molecular materials across micrometer distances via the resonant coupling of molecular excitons to the standing waves of a confined electromagnetic field.30–32 

Yet, recent ultrafast microscopy experiments revealed polariton propagation speeds far below the group velocities predicted from the to dynamical disorder originating from exciton–phonon interactions, which scatter polaritons and disrupt coherent wavepacket propagation.35,37–41 In support of this interpretation, temperaturedependent measurements in perovskite microcavities35 show that transport velocities approach the expected group velocity as the system approaches T → 0 K, where thermal phonon populations vanish and inelastic phonon-assisted scattering is suppressed. Further corroboration of the important role played by phonon-assisted scattering in polariton transport was provided by semiclassical simulations including intramolecular and intermolecular exciton–phonon interactions.35,37,38,40,42 

Yet even in the absence of phonons, polariton transport could remain unexpectedly slow. Static disorder arising from sample inhomogeneities43 introduces elastic scattering that limits coherent propagation. Our recent theoretical works examining coherent transient exciton propagation in polaritonic wires showed that, in fact, static disorder can significantly slow down exciton-polariton transport44,45 (see also Refs. 17 and 19). However, static disorder is most impactful in one-dimensional systems,46–49 and the typical magnitude of static disorder-induced changes in polariton group velocity in higher dimensions remains unknown. 

In this work, we directly address this open question. We employ a nonperturbative method50,51 to quantify the effects of static exciton disorder on polariton group velocities in organic microcavity exciton-polaritons. Our results establish the typical magnitude of polariton group velocity renormalization induced by resonant scattering. We find static disorder leads to potentially significantly slower transport, mainly in lower polariton modes at large in-plane wave vectors, where the exciton content is high. Strong renormalization emerges only when the mean exciton energy fluctuation approaches half the Rabi splitting. Perturbative estimates support these trends and provide analytical insight into the numerically obtained behavior. 

## METHODS

We model an isotropic and homogeneous energetically disordered molecular ensemble in the thermodynamic limit under strong coupling with a microcavity with perfectly reflective mirrors. The Hamiltonian that characterizes this system can be written as 

$$
H = H _ {\mathrm{M}} + H _ {\mathrm{L}} + H _ {\mathrm{LM}}, \tag {1}
$$

$\begin{array} { r } { H _ { \mathrm { M } } = \sum _ { i } ^ { N _ { \mathrm { M } } } \left( \hbar \omega _ { i } + \sigma _ { i } \right) \left| i \right. \left. i \right| } \end{array}$ ing fluctuations in excitation energies $\left( \sigma _ { i } \right)$ that characterize the static disorder of the system. $\begin{array} { r } { H _ { \mathrm { L } } = \sum _ { m \mathbf { q } \lambda } \hbar \omega _ { c } ( q , m ) a _ { m \mathbf { q } \lambda } ^ { \dagger } a _ { m \mathbf { q } \lambda } } \end{array}$ is the empty cavity Hamiltonian describing photon modes with frequency $\omega _ { c } ,$ , inplace wave vector ${ \mathbf { q } } ,$ and polarization λ for each branch $m .$ Finally, $H _ { \mathrm { L M } }$ is the interaction Hamiltonian expressed in the Coulomb gauge using the rotating-wave-approximation. A more detailed description of the Hamiltonian, including this interaction term, can be found in Refs. 50 and 52. 

From the Hamiltonian and regime described above, polariton energies $E _ { \mathrm { P } } ( q )$ (with $\mathrm { P } = \mathrm { L P o r U P } )$ can be approximated as solutions to an effective medium dispersion relation originally derived in the context of molecular polaritons by Litinskaya and Reineke $\cdot ^ { 5 0 }$ and that can be expressed as 

$$
E _ {\mathrm{P} (q)} - E _ {\mathrm{C} (q, m)} = \frac {\Omega_ {\mathrm{R}} ^ {2}}{4} \int_ {- \infty} ^ {\infty} d E ^ {\prime} \frac {\rho (E ^ {\prime})}{E _ {\mathrm{P} (q)} - E ^ {\prime}}, \tag {2}
$$

where $E _ { \mathrm { C } } ( q , m )$ is the energy of the photon mode with in-plane√ wave vector magnitude $q = \sqrt { q _ { x } ^ { 2 } + q _ { y } ^ { 2 } }$ , and longitudinal wave vector $k _ { z } ( m ) = m \pi / L _ { \mathrm { C } } ,$ , with $m \in \mathbb { N } _ { > 0 }$ for transverse-electric and $m \in  { \mathbb { N } } _ { 0 }$ for transverse-magnetic modes, $\Omega _ { \mathrm { R } }$ is the Rabi splitting, which is proportional to the spatially averaged transition dipole moment and the square root of the density of the molecular ensemble. The probability distribution $\rho ( E )$ models the exciton static disorder (inhomogeneous broadening). Here, we assume $\rho ( E )$ is a normal distribution with mean $E _ { \mathrm { M } }$ and variance σ $r ^ { 2 } / 2$ , 

$$
\rho (E) = \frac {1}{\sigma \sqrt {\pi}} \exp \left[ - \left(E - E _ {\mathrm{M}}\right) ^ {2} / \sigma^ {2} \right]. \tag {3}
$$

With this choice, $\operatorname { E q . } \left( 2 \right)$ can be written as 

$$
E _ {\mathrm{P} (q)} - E _ {\mathrm{C} (q, m)} = \frac {\Omega_ {\mathrm{R}} ^ {2} \sqrt {\pi}}{4 i \sigma} e ^ {- \frac {[ E _ {\mathrm{P} (q)} - E _ {\mathrm{M}} ] ^ {2}}{\sigma^ {2}}} \operatorname{erfc} \left[ \frac {E _ {\mathrm{P} (q)} - E _ {\mathrm{M}}}{i \sigma} \right], \tag {4}
$$

where erfc is the complementary error function.53 Due to the fast growth of $\operatorname { e r f c } ( - i x )$ for large $x \in \mathbb { R }$ , it is numerically advantageous to work instead with the scaled complementary error function $\operatorname { e r f c x } ( z ) = \exp { \left( z ^ { 2 } \right) } \operatorname { e r f c } ( z )$ , where $z = - i \big [ E \big ( q \big ) - E _ { \mathrm { M } } \big ] / \sigma .$ , as this substitution preserves floating-point accuracy at large ∣z∣. 

The solutions to Eq. (4) are complex-valued polariton energies $E _ { \mathrm { P } } ( q )$ for any nonzero disorder strength $\sigma > 0 ,$ with the imaginary part characterizing the finite polariton lifetime due to elastic resonant scattering. $5 4 - 5 6$ Static disorder also shifts the real part of $E _ { \mathrm { P } } ( q )$ and leads to the renormalized group velocity, 

$$
\nu_ {g} (q) = \frac {1}{\hbar} \frac {\partial}{\partial q} \mathrm{Re} [ E _ {\mathrm{P} (q)} ]. \tag {5}
$$

As discussed in detail in Refs. 50 and 52, this approach is suitable so long as the polariton spectral function $A ( \mathbf { q } , E ) = \langle \mathbf { q } | \delta ( E - H ) | \mathbf { q } \rangle$ (where q corresponds to the microcavity mode with in-plane wave vector q) is narrowly centered around Re $E _ { \mathrm { P } } ( q )$ . In other words, Eq. (5) provides a non-perturbative estimate of the renormalized polariton group velocity if the disorder-induced broadening $\delta q$ satisfies $\delta q / q < 1$ , where δq can be estimated from the imaginary part of the renormalized polariton energy,4,50,52 

$$
\delta q = \frac {\mathrm{Im} [ E _ {\mathrm{P} (q)} ]}{\hbar \nu_ {g} (q)}. \tag {6}
$$

Figure 1 shows that the effect of static disorder on the dispersion of the examined systems is similar: LP frequencies are reduced, whereas UP frequencies are blueshifted. In the LP branch, the effect is vanishingly small at q close to 0 and becomes more relevant as q becomes larger. Conversely, in the UP branch, static disorder effects are maximal at $q \to 0$ and become negligible at large q. These trends can be understood based on the exciton content of each polariton mode as presented in Figs. 1(c) and 1(d). At $q \to 0 _ { \mathrm { : } }$ , the LP modes are mostly photonic and, therefore, are negligibly affected by matter static disorder, whereas the UP has much greater exciton content, and the corresponding mode frequencies are much more sensitive to static disorder. The same reasoning holds at large q, where the increased exciton content of LP modes yields a greater energy renormalization. 

The renormalization of the polariton dispersion by static disorder presented in Fig. 1 is only significant when σ approaches $\Omega _ { \mathrm { R } } / 2$ , and even then, only the frequencies of modes with high exciton content (>50%) are substantially shifted. Observing these variations would require polariton homogeneous linewidths to be smaller than the change in energy induced by disorder-induced elastic scattering. To verify if that is the case, the dispersion curves in Figs. 1(a) and 1(b) include the shaded regions representing the energy uncertainty $\pm 2 \operatorname { I m } [ E _ { \mathrm { P } } ( q ) ]$ imparted by resonance scattering. This uncertainty is generated by the exciton inhomogeneous broadening and neglects additional broadening mechanisms such as microcavity photon leakage and dynamical disorder, which further increase the polariton energy width. Nevertheless, there is already significant overlap between the zero-disorder and the broadened renormalized polariton dispersions obtained with the considered relative disorder strengths $( \sigma / \Omega _ { \mathrm { R } } )$ , therefore suggesting that the renormalized dispersion is unlikely to be observable in linear optical response measurements under typical experimental conditions. In addition, Fig. 1 shows that the gap between LP and LP branches remains observable even at $\sigma / \Omega _ { \mathrm { R } } = 0 . 5$ , even when considering the energy uncertainty. This agrees with a different model we have employed before, where gap closure is only observed at static disorder strengths close to 80%.45

The static disorder-induced lowering of LP and raising of UP energies can be understood from a weak disorder perturbative expansion of Eq. (4) in powers of $\sigma / \Omega _ { \mathrm { R } }$ . For modes with $\bar { \delta } q / q \ll 1$ , in the limit where $\sigma / \Omega _ { \mathrm { R } }  0 , | E _ { \mathrm { P } } ( q ) - E _ { \mathrm { M } } | / \sigma  \infty$ , and we can employ the asymptotic expansion,58 

$$
\operatorname{erfc} (z) \sim \frac {e ^ {- z ^ {2}}}{z \sqrt {\pi}} \left[ \frac {1}{z} - \frac {1}{2 z ^ {3}} + O \left(z ^ {- 5}\right)\right], \quad z \rightarrow \infty . \tag {7}
$$

Inserting the first two terms of $\operatorname { E q . } \ ( 7 )$ into Eq. (4) leads to the following weak disorder renormalized dispersion relation valid to $O ( \sigma ^ { 2 } / \Omega _ { \mathrm { R } } ^ { \ - 2 } )$ , 

$$
\left[ E _ {\mathrm{P} (q)} - E _ {\mathrm{C} (q, m)} \right] \left[ E _ {\mathrm{P} (q)} - E _ {\mathrm{M}} \right] - \frac {\Omega_ {\mathrm{R}} ^ {2}}{4} = \frac {\Omega_ {\mathrm{R}} ^ {2} \sigma^ {2}}{8 \left[ E _ {\mathrm{P}} ^ {(0)} (q) - E _ {\mathrm{M}} \right] ^ {2}}, \tag {8}
$$

where $E _ { \mathrm { P } } ^ { ( 0 ) } ( q )$ is the polariton energy obtained from Eq. (2) in the limit where $\sigma \to 0$ and we used $E _ { \mathrm { P } ( q ) } = E _ { \mathrm { P } } ^ { ( 0 ) } ( q ) + O \big ( \sigma ^ { 2 } \big )$ . The leading change in polariton energies induced by weak disorder can be written as 

$$
\left[ E _ {\mathrm{P} (q)} - E _ {\mathrm{C} (q, m)} \right] \left[ E _ {\mathrm{P} (q)} - E _ {\mathrm{M}} \right] - \frac {\tilde {\Omega} _ {\mathrm{R}} ^ {2}}{4} \approx 0, \tag {9}
$$

where 

$$
\tilde {\Omega} _ {\mathrm{R}} \approx \Omega_ {\mathrm{R}} \sqrt {1 + \frac {\sigma^ {2}}{2 \left[ E _ {\mathrm{P}} ^ {(0)} (q) - E _ {\mathrm{M}} \right] ^ {2}}}. \tag {10}
$$

It follows that $\tilde { \Omega } _ { \mathrm { R } } > \Omega _ { \mathrm { R } } ;$ hence, static disorder increases the split-$E _ { \mathrm { L P } } ( q ) < E _ { \mathrm { L P } } ^ { ( 0 ) } ( q )$ and $E _ { \mathrm { U P } } ( q ) > E _ { \mathrm { U P } } ^ { ( 0 ) } ( q )$ . This simple analysis also explains the asymmetric renormalization effect on polariton dispersion shown in Fig. 1. The change in energy is greatest for a given q at the branch P with smaller $\left| E _ { \mathrm { P } } ( q ) - E _ { \mathrm { M } } \right|$ . In red-detuned microcavities [where $E _ { \mathrm { C } } ( 0 ) < E _ { \mathrm { M } } ,$ , as in both systems considered in Fig. 1], this perturbative treatment holds for UP modes with large q and LP modes with small $q ,$ where $\left| E _ { \mathrm { P } } ( q ) - E _ { \mathrm { M } } \right| \gg \sigma . \mathrm { A s } E _ { \mathrm { P } } ( q )$ approaches the bare exciton energy (UP modes with small q and LP modes with large q), the weak disorder assumption breaks down. However, these modes have $\delta q / q \geq 1$ , and therefore, Eq. (4) is no longer applicable. 

From the previous discussion on the renormalization of the polariton dispersion relation, we can deduce that static disorder reduces both lower and upper polariton group velocities, as we explain next. Let the renormalized polariton energies be written as $E _ { \mathrm { P } ( q ) } = E _ { \mathrm { P } } ^ { ( 0 ) } ( q ) + \hbar \delta _ { \mathrm { P } } ( q )$ $\delta _ { \mathrm { P } } ( q )$ energy shift. The corresponding renormalized group velocities are given by $\nu _ { \mathrm { P } } ( q ) = \hbar ^ { - 1 } \partial E _ { \mathrm { P } ( q ) } / \partial q = \nu _ { \mathrm { P } } ^ { ( 0 ) } ( q ) + \delta _ { \mathrm { L P } } ^ { \prime } ( q )$ , where $\delta _ { \mathrm { L P } } ^ { \prime } ( q )$ $= \partial \delta _ { \mathrm { P } } ( q ) / \partial q$ . As q grows, $\overset { \cdot } { \sigma } / \vert E _ { \mathrm { L P } } ( q ) - E _ { \mathrm { M } } \vert$ increases, resulting in an enhanced polariton gap and greater magnitude LP redshift [see Eq. (10)]. This leads to the conclusion that $\delta _ { \mathrm { L P } } ^ { \check { \prime } } ( q ) < 0$ and, therefore, static disorder induces slower LP propagation, $\mathrm { i . e . , } \nu _ { \mathrm { L P } } ( q ) < \nu _ { \mathrm { L P } } ^ { ( 0 ) } ( q )$ . For the UP branch, as q increases, $\tilde { \Omega } _ { \mathrm { R } }  \Omega _ { \mathrm { R } }$ [see Eq. (10)]. Hence, as shown by Fig. 1, the effect of static disorder on the UP dispersion subsides at high $q , \mathrm { i . e . , } \delta _ { \mathrm { U P } } ( q ) \to 0 .$ . Given that $\delta _ { \mathrm { U P } } \geq 0$ [from Eqs. (9) and (10)] and that $\delta _ { \mathrm { U P } }$ becomes smaller as q increases, we conclude that $\delta _ { \mathrm { U P } } ^ { \prime } ( q ) < 0$ and $\nu _ { \mathrm { U P } } ( q ) < \nu _ { \mathrm { U P } } ^ { ( 0 ) } ( q )$ . In summary, a perturbative expansion of Eq. (4), detailed in Eqs. (7)–(10), provides qualitative insight into the limiting behaviors of static disorder-induced renormalization. These arguments show that static disorder tends to reduce polariton group velocities, with the extent of the reduction depending on both the disorder strength and the excitonic content of the polaritonic mode. This trend is consistent with the group velocities obtained from the full non-perturbative model, as shown in Fig. 2. 

Because substantial intermolecular interactions protect polaritons from localization,36,59 the actual group velocity renormalization due to static disorder in exciton-polaritons arising in organic semiconductors with strong dipolar coupling is likely even weaker than what is shown here. Hence, our results support the perspective that at finite temperatures (or low temperatures in systems with strong vibronic coupling42), dynamical disorder arising from phonon scattering likely dominates over static effects. This conclusion is consistent with temperature-dependent group velocity measurements by Xu et al.35

Panels (a) and (b) confirm the intuitive trend that less disorder is needed to slow polaritons when their exciton character is larger. Quantitatively, the crossover boundary between negligible and significant velocity renormalization (as defined by the 10% renormalization criterion) follows approximately the relation $P _ { \mathrm { M } } ( q ) \propto ( \sigma / \Omega _ { \mathrm { R } } ) ^ { - 1 }$ for $\delta q / q < 1$ . 

Overall, even at strong static disorder, $\sigma / \Omega _ { \mathrm { R } } > 0 . 5 ,$ , the computed velocity reduction remains modest compared with the values reported in Refs. 34 and 35. This finding reinforces the view that phonon-assisted scattering, rather than static disorder, dominates the experimentally observed molecular exciton-polariton group velocity renormalization under typical conditions. 

Taken together with the preceding analysis, Fig. 3 supports the view that static disorder can slow polaritons appreciably only when they are strongly excitonic and no longer possess a welldefined in-plane wave vector. Under typical experimental conditions at moderate temperatures, static disorder, therefore, plays, at most, a supporting role compared with dynamical disorder arising from exciton–phonon scattering. 

## CONCLUSIONS

We implemented a nonperturbative framework50 to estimate how resonance scattering induced by static energetic disorder renormalizes molecular polariton group velocities. This approach requires only the probability density function for the exciton transition energy, the collective light–matter interaction strength as provided by the Rabi frequency, and the bare microcavity dispersion, so it can be readily applied to a wide range of material platforms. 

Our numerical simulations employing parameters corresponding to the polaritonic systems experimentally probed in Refs. 34 and 35 reveal that static disorder can explain at most a minor fraction of the observed group velocity renormalization. Thus, we are led to conclude that most of the reported polaritonic slowdown stems from dynamical (phonon-assisted) disorder.39 This mechanism is likely dominant in most molecular exciton-polariton systems, especially in the presence of significant vibronic coupling and moderate temperatures, where inelastic scattering induced by exciton–phonon interactions dominates over elastic scattering due to static fluctuations. Nevertheless, at low temperatures, the thermal phonon population dwindles, and elastic scattering induced by a frozen disordered environment takes over. Under these conditions, materials exhibiting strong static energetic disorder and weak vibronic coupling will show polariton group velocity renormalization mirroring the behavior reported here.
