proposal-szr.md : A total explanation of the whole project. All markdown files under this polariton content are highly related to the static perspective of the proposal, which wants to study how vibronic coupling, static/dynamic disorder and other possible factors influence the original band structure of polariton using full-quantum methods like DMRG/TD-DMRG.

balasubrahmaniyam2023naturemat.md : A important reference which finished an experiment of polariton transport and gave out a phenomenological model of polariton group velocity.

microscopic-theory-of-polaron-polariton-dispersion-and-propagation.md : A theoretical method to calculate group velocity of polariton system with classical phonon field + Floquet quantization, and get an analytical quasi-band structure in extended space due to vibronic coupling.

s41467-025-62276-x.md : A theory uses finite-temperature Green's function and diagrammatic perturbation theory to calculate how vibronic coupling renormalizes group velocity.

124120_1_5.0288551.md : A theoretical study which uses nonperturbative effective medium approach (Litinskaya-Reineker formalism) and shows that static energetic disorder can renormalize polariton dispersion and reduce group velocity, especially for exciton-rich polaritons.
